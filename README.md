# 🛍️ Arraso Moda Feminina

Site institucional responsivo desenvolvido para a loja **Arraso Moda Feminina**, com o objetivo de fortalecer a presença digital da empresa, organizar informações importantes e facilitar o contato com clientes.

🔗 **Acesse o site publicado:**
https://henriquedu.github.io/arraso-moda-feminina/

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma **Prática Extensionista**, com foco na aplicação de uma solução digital para um empreendimento real.

A proposta foi criar um site simples, bonito, funcional e responsivo para a loja **Arraso Moda Feminina**, permitindo que clientes encontrem com facilidade informações sobre a empresa, categorias de produtos, formas de contato, localização, redes sociais e política de trocas.

O site foi estruturado em múltiplas páginas, oferecendo uma navegação mais organizada e uma experiência mais próxima de uma loja virtual institucional.

---

## 🎯 Objetivo

O objetivo principal do projeto foi desenvolver uma solução digital para melhorar a visibilidade da loja e organizar sua comunicação com o público.

A solução busca contribuir para:

* Fortalecer a presença digital da loja;
* Apresentar a marca de forma mais profissional;
* Organizar informações importantes em um único ambiente;
* Facilitar o contato via WhatsApp, Instagram e Facebook;
* Disponibilizar localização da loja pelo Google Maps;
* Apresentar categorias de produtos de forma clara;
* Melhorar a experiência de navegação em celular e computador.

## 🖥️ Páginas do site

### 🏠 Início

Página principal com apresentação da loja, chamada comercial, categorias em destaque e acesso rápido aos principais canais de atendimento.

### 👗 Feminino

Página com categorias voltadas à moda feminina.

Categorias incluídas:

* Vestidos;
* Calças;
* Blusas;
* Blazer;
* Shorts;
* Saia;
* Looks e Combinações.

### ✨ Looks e Combinações

Categoria criada para apresentar sugestões de moda para o dia a dia, com foco em combinações práticas, confortáveis e estilosas.

O card **“Moda para o dia a dia”** da página inicial direciona para esta categoria.

### 👜 Bolsas

Página dedicada à apresentação de bolsas femininas e modelos que combinam com diferentes estilos e rotinas.

### 💍 Acessórios

Página voltada para acessórios femininos, como brincos, colares e cintos.

### 📞 Contato

Página com os principais canais de comunicação da loja:

* WhatsApp;
* Instagram;
* Facebook;
* Grupo VIP;
* E-mail;
* Endereço com link para Google Maps.

### 👩‍💼 Quem Somos

Página institucional com a história da loja e apresentação da responsável pela Arraso Moda Feminina.

### 🔁 Trocas e Devoluções

Página com informações sobre a política de trocas, orientações para clientes e contato com a loja.

### 🔒 Política de Privacidade

Página com informações institucionais sobre privacidade e uso de dados.

## 🚀 Como executar localmente

Para visualizar o projeto no computador:

1. Clone o repositório:

```bash
git clone https://github.com/Henriquedu/arraso-moda-feminina.git
```

2. Acesse a pasta do projeto:

```bash
cd arraso-moda-feminina
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para visualizar o site localmente.
