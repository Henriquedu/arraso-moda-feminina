# 💖 Arraso Moda e Acessórios Femininos

Site institucional responsivo desenvolvido para a loja **Arraso Moda e Acessórios Femininos**, com o objetivo de fortalecer sua presença digital, organizar informações importantes da marca e facilitar o contato com clientes por meio de canais digitais.

🔗 **Acesse o site publicado:**
https://henriquedu.github.io/arraso-moda-feminina/

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma **Prática Extensionista** do curso de **Gestão da Tecnologia da Informação**, com foco na aplicação prática da tecnologia para atender uma necessidade real de um pequeno negócio.

A proposta consiste na criação de uma solução digital simples, moderna, responsiva e funcional para apoiar a comunicação da loja Arraso, centralizando informações sobre a marca, categorias de produtos, canais de atendimento, localização, política de trocas e dados institucionais.

---

## 🎯 Objetivo

Desenvolver um site profissional e acessível para a loja **Arraso Moda e Acessórios Femininos**, permitindo que clientes encontrem de forma rápida e organizada informações sobre:

* A história da loja;
* Categorias de produtos;
* Canais de contato;
* Localização;
* Redes sociais;
* Grupo de descontos;
* Política de trocas;
* Política de privacidade.

O projeto busca contribuir para a melhoria da presença digital da loja e facilitar a comunicação com o público.

## 🖥️ Páginas do site

O projeto foi estruturado em múltiplas páginas, simulando a navegação de uma loja online profissional.

### 🏠 Home

Página inicial com apresentação da loja, categorias principais, chamada para o grupo VIP e informações institucionais.

### 👗 Feminino

Página voltada para peças femininas, com subcategorias como:

* Vestidos;
* Calças;
* Blusas;
* Blazer;
* Shorts;
* Saias.

### 👜 Bolsas

Página destinada à apresentação de bolsas selecionadas pela loja.

### 💍 Acessórios

Página com categorias de acessórios, como:

* Brincos;
* Colares;
* Cintos.

### 📞 Contato

Página com os principais canais de atendimento da loja:

* WhatsApp;
* E-mail;
* Instagram;
* Facebook;
* Grupo VIP;
* Localização no Google Maps.

### 💬 Quem Somos

Página com a história da loja e apresentação da Daiane, responsável pela Arraso.

### 🔁 Trocas e Devoluções

Página com orientações claras sobre a política de trocas da loja.

### 🔒 Política de Privacidade

Página com informações sobre tratamento de dados, privacidade e segurança dos usuários.

## 🚀 Como executar localmente

Para visualizar o projeto no computador:

1. Clone o repositório:

```bash
git clone https://github.com/Henriquedu/arraso-moda-feminina.git
```

2. Acesse a pasta do projeto:

```bash
cd arraso-moda-feminina
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para visualizar o site localmente.
